Entry for the [make.fun bounty "How Many Tabs Do You Have Open?"](https://make.fun/competitions/u-danu-how-many-tabs-do-you-have-open-d86e783d).

## Entry

`247`

## What it does

`main.ts` deterministically writes exactly `247` — the entrant's honest count of open browser tabs, digits only, no trailing newline — to `/output/entry.txt`. No randomness, no network, no input.

## Run

```sh
bun main.ts
```
